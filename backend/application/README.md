# Синтетический engine

`FixtureAnalysisEngine` передаёт фиксированный synthetic-корпус через source bridge, `AnalysisPipeline` и `BrokerModelClient` с внедрённым детерминированным transport в памяти. Он не вызывает сеть, shell или реальную модель. Fake-результат не доказывает качество генерации, экспозицию компании или позицию банка.

Источники имеют ID с префиксом `fixture:`, без внешнего URL, и признак `synthetic`. Экспозиция остаётся неизвестной или условной. Engine принимает две demo-компании и CFO/COO, ограничивает размер корпуса и результатов. После проверки pipeline он сопоставляет evidence IDs с нормализованными source IDs. При ошибке он возвращает безопасный отказ без карточек.
