# Backend

FastAPI обслуживает компании, анализ, ленту, карточки, уточнения и вопросы. Python 3.14.3 и прямые зависимости закреплены в `requirements.txt`; тестовые зависимости в `requirements-dev.txt`, контейнерный набор в [runtime lock](../deploy/runtime-requirements.lock).

[Настройка](../docs/setup.md) описывает synthetic quickstart и операторские входы. [Архитектура](../docs/architecture.md) описывает агентную цепочку, происхождение и идемпотентность. [Проверки](../docs/testing.md) содержат переносимые команды.

При выключенном доступе health работает, бизнес-маршруты возвращают `503 auth_unconfigured`. Локальный allowlist не является банковским IAM. В `mvp_offline` модель fake; API анализа читает подготовленную новостную БД. Финальный `product_server.py` обновляет официальные источники при старте и раз в час без вызова LLM. Источники сохраняют собственные synthetic-признаки: fake-модель не превращает реальные материалы в синтетические.

Диалог принимает `POST /api/v1/insights/{id}/questions` с `question_id,answer,idempotency_key` и `/messages` с `text,idempotency_key`. Текст содержит 1..2000 символов. Повтор payload/key возвращает сохранённый результат; изменённый payload с тем же ключом даёт 409. Пользовательский ввод остаётся непроверенным источником своей компании и роли.

Снимки и evidence refs проходят проверку до записи. Неизвестный источник завершает run ошибкой без карточек; fingerprint включает профиль, источники, роль и revision пользователя. Trace содержит статусы, этапы и ID. Полные входные CSV и банковские тексты API не выдаёт. Подробные границы в [ограничениях](../docs/limitations.md).
