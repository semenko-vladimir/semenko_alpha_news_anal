# Клиент модельного брокера

`BrokerModelClient.generate(context, correction=None)` возвращает недоверенный JSON-кандидат для проверки в `AnalysisPipeline`. Обычный конструктор требует явно переданный транспорт; тесты используют fake. `BrokerModelClient.live` включает отдельный SSH transport по явному операторскому назначению. Приложение поддерживает этот адаптер, но по умолчанию использует fake.

Оператор задаёт `ALPHA_BROKER_HOST` и `ALPHA_BROKER_SCRIPT` по [инструкции](../../docs/setup.md). Значения по умолчанию: `model-broker`, `/opt/alpha-broker/broker.py`. Клиент ограничивает синтаксис host и абсолютного пути для безопасности удалённой команды OpenSSH. Job с `task_id`, `model`, `prompt` проходит через stdin при `shell=False`. Приложение не передаёт prompt в аргументы.

Транспорт ограничивает prompt 12000 символами, stdout 2100000 байтами и операцию 100 секундами. Отдельные потоки пишут stdin, читают stdout и отбрасывают stderr. При переполнении или таймауте transport завершает собственный процесс и освобождает его ресурсы. Это ограничение stdout, не общий предел памяти Python.

Клиент привязывает task ID к fingerprint модели и prompt. Изменённый prompt, correction и повтор после неопределённого исхода запрещены. Новый ID не разрешает обход квоты или неопределённого результата. Budget/auth/timeout проходят в типизированные ошибки цепочки. Модельный ответ проходит отдельную проверку схемы, evidence refs, экспозиции и атрибуции банка. Fake-тесты не доказывают качество, доступность или тарификацию реальной модели.
