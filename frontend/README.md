# Интерфейс

React, TypeScript и Vite. Пользователь выбирает компанию и CFO/COO, запускает анализ, читает ленту, открывает источники, отвечает на уточнение и задаёт вопрос. Backend определяет режим модели; интерфейс показывает тестовые и синтетические данные, а также неизвестные сведения.

[Настройка и сборка](../docs/setup.md). [Проверки и браузер](../docs/testing.md).

Dev-сервер проксирует `/api` на `127.0.0.1:8000`. `ALPHA_UI_API_TARGET` меняет адрес назначения только на стороне Vite. В релизной сборке Nginx обслуживает интерфейс и API с одного origin.

Диалог хранит черновики для каждой компании, роли и карточки в текущей вкладке. Закрытие карточки не повторяет отправленный POST. При неизвестном результате UI блокирует новые отправки в этом контексте до конца сессии; обновление страницы очищает локальное состояние, сервер сохраняет идемпотентность. Тесты жизненного цикла и рендеринга проверяют эти переходы без браузера.
