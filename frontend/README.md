# Интерфейс

React, TypeScript и Vite. Пользователь выбирает компанию и CFO/COO, запускает анализ, читает ленту, открывает источники, отвечает на уточнение и задаёт вопрос. Backend определяет режим; UI показывает fake/synthetic и неизвестные сведения.

[Настройка и сборка](../docs/setup.md). [Проверки и браузер](../docs/testing.md).

Dev-сервер проксирует `/api` на `127.0.0.1:8000`. `ALPHA_UI_API_TARGET` меняет target только на стороне Vite. Production использует same-origin Nginx.

Диалог хранит черновики по company/role/insight в текущей вкладке. Закрытие карточки не повторяет отправленный POST. При неизвестном результате UI блокирует новые отправки в этом контексте до конца сессии; обновление страницы очищает локальное состояние, сервер сохраняет идемпотентность. Lifecycle/render tests проверяют эти переходы без браузера.
