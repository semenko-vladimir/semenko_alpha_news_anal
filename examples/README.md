# Синтетические наборы

`quality-010/` и `quality-011/` содержат отдельные синтетические `cases.json` и `labels.json`. Cases задают входы для моделей; labels хранят инженерные ожидаемые свойства для проверок. Не объединяйте labels с данными, которые передают модели.

Оба набора используют вымышленные случаи. Единицы измерения и периоды для неопределённых значений остаются неизвестными. Метки `fake` сохраняют свой смысл и не подтверждают факты реального бизнеса. Авторы подготовили инженерные labels; независимый специалист их не оценивал. Эти fixtures помогают проверять структуру и ограничения вывода, но не измеряют полезность для клиентов.
