# HTTP smoke локального деморежима

Из корня выполните `python -B scripts/verify-local-demo.py`. Установите backend-зависимости в выбранный Python. Runner использует этот же интерпретатор; `--python` задаёт другой.

Runner запускает `backend/app.py` через Uvicorn и обращается только к loopback HTTP. Он создаёт собственные SQLite и лог в `.tmp/demo-smoke/`, ограничивает HTTP-запрос и старт сервера 15 секундами и закрывает свои процессы.

Проверка охватывает выключенный доступ, allowlist двух demo-компаний, четыре company/role контекста, повторную идемпотентность, ленту без дублей, ошибки роли и scope, evidence refs и сохранение после restart. Публичный API не даёт изменить fingerprint, поэтому этот smoke не проверяет конфликт изменённого входа. Model и источники synthetic/fake. Проверка не подтверждает работу реальной модели или банковской интеграции.
