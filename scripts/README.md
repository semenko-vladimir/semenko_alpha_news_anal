# Скрипты

- `prepare_product.py` готовит отдельный каталог с сохраняемой историей и опционально четыре приватных профиля, не меняя исходные файлы.
- `run_product.py` запускает финальный UI/API; живой режим требует явного включения и проверенного статуса брокера.
- `update_product_data.py` обновляет официальные новости без LLM; `--status` читает состояние без сети.
- `broker_socket_bridge.py` предоставляет приватный Linux Unix-сокет к существующему брокеру, без доступа приложения к ключу.
- `configure_product_access.py` создаёт закрытый демодоступ и локальный TLS, выводя только пути к файлам оператора.
- `prepare_mvp_demo.py` создаёт новый синтетический набор в `.tmp/` и Compose env без ключей.
- `run_mvp.py` обслуживает собранный UI и offline API на одном loopback-порту.
- `verify-agent-chain.py` проверяет цепочку с fake transport.
- `verify-local-demo.py` проверяет прежний детерминированный демонстрационный режим через HTTP.
- `verify-mvp.py --offline` запускает расширенные проверки с отдельно подготовленными входами и браузерным окружением.
- `run-local-demo.ps1` и `stop-local-demo.ps1` управляют собственными dev-процессами прежнего деморежима. Для launcher создайте `.venv` в Windows и установите frontend-зависимости.
- `model-broker.ps1` предоставляет операторские health/status/configure; обычный запуск приложения не требует broker.
