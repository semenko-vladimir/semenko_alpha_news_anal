# Альфа Хак: персонализированная бизнес-аналитика

Проект хакатона Альфа-Банка для руководителей компаний с выручкой свыше 15 млрд рублей. Руководитель выбирает компанию и роль CFO или COO, запускает анализ внешних событий, изучает риски и возможности и проверяет источники каждого вывода. В карточке он уточняет связь события с бизнесом и задаёт вопрос.

В целевой версии сервис получает контекст компании из подключённых банковских систем с учётом прав доступа пользователя. Руководитель выбирает компанию и свою роль, уточняет профиль и добавляет недостающие сведения о бизнесе. Для анализа сервис сопоставляет этот контекст с внешними новостями и аналитикой банка.

В текущем прототипе оператор подключает локальные файлы. Публичный пример использует вымышленные компании и события и явную fake-модель. Подключения к банковским системам и банковского IAM нет. Единицы выручки и eligibility остаются неизвестными, поэтому приложение не применяет порог 15 млрд к данным.

## Первый запуск

Нужны Python 3.14 с SQLite FTS5 и Docker Compose v2. Выполните команды из корня проекта (PowerShell):

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r deploy/runtime-requirements.lock
.venv/Scripts/python.exe -B scripts/prepare_mvp_demo.py --output .tmp/mvp-synthetic --port 8087
docker compose --env-file .tmp/mvp-synthetic/compose.env config
docker compose --env-file .tmp/mvp-synthetic/compose.env up --build -d
```

Откройте http://127.0.0.1:8087/. Выберите компанию, CFO или COO, нажмите кнопку анализа и откройте карточку. Проверьте источники, неизвестные сведения и уточнение. Модель fake: этот пример проверяет работу приложения, а качество генерации реальной LLM требует отдельной оценки. Генератор не читает предоставленные организаторами материалы и откажется перезаписать существующую папку.

Для остановки выполните `docker compose --env-file .tmp/mvp-synthetic/compose.env down`. В Linux/macOS используйте `.venv/bin/python` вместо `.venv/Scripts/python.exe`. Установка зависимостей и сборка образов требуют доступа к реестрам пакетов.
