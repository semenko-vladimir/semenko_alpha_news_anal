Что выявил реальный тест

CFO сделал неподтверждённый вывод о кредитных лимитах; команда скрыла карточку.

В пробе диалога модель отвергла внедрённую инструкцию. Команда исправила ложную остановку и проверила записанный ответ без новой генерации. Независимый ревьюер выполнил 23 проверки; история ошибки сохранена.

Оператор включает этот эксперимент отдельно. Локальные ID не входят в шесть разрешённых моделей кейса; основной маршрут на них не переключается.
