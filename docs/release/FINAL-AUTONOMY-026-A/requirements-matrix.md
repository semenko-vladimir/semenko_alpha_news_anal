# Матрица кейса и доказательств

Основание — предоставленный кейс «Альфа Хак: Новостная аналитика», страницы 8–12 и 14; текст сверили с производным извлечением исходного PDF. Здесь смысловые пересказы критериев, не балльная самооценка и не независимая приёмка. Исходный PDF в комплект не включён.

| Критерий | Что реализовано и чем проверено | Что остаётся |
| --- | --- | --- |
| 1. Бизнес-контекст клиента и релевантные новости | Публичные профили 11 компаний; исходные обезличенные CSV подключаются отдельно; фильтр релевантности, CFO/COO; свежий clean-прогон candidate проверил 22/22 HTTP-пары | Экспертная оценка релевантности на новых событиях; единицы/роли физлиц не угадываются |
| 2. Содержательные последствия, риски и возможности | Условные AI-сценарии; облачный ответ CFO прошёл формат exact5/schema, 366 completion-токенов, 4.882 с | Финансовый критерий 3 не пройден: не указана зависимость оплаты от приёмки как условие финансового эффекта. Облачный ответ COO с Markdown отклонён: обрыв JSON на 512 токенах; общий stop, третья попытка не отправлена. Небезопасная локальная карточка CFO №6 скрыта. Полезность не доказана |
| 3. Банковская аналитика | Отдельный маршрут с частным банковским индексом и тип bank_opinion; публичный режим явно показывает отсутствие позиции | Качество совместной LIVE-интерпретации и права на публикацию банковских материалов |
| 4. Сведение источников и фактология | Evidence refs, snapshot, профиль/периоды, source links, guard категорий/чисел/модальности | Проверка формулировок регулярными выражениями не доказывает истинность и не заменяет проверку эксперта |
| 5. Работа с новыми событиями | Обновление реальных источников с сохранением последней успешной загрузки, версия входа/политики | Репрезентативный набор ранее не виденных событий; исторический локальный пилот охватил одно событие |
| 6. Полный пользовательский путь | Выбор → анализ → источники/оговорки/trace → уточнение; контейнеры нового кандидата стали healthy, HTTP 22/22 и Chrome 1440/390/320 прошли в FAKE-режиме; после остановки и запуска сохранились 28 новостей и карточка | Реальный диалог последней пробы завершился ошибкой в пилоте; исправление проверено offline, новой живой генерации после исправления не было |
| 7. Расширяемость | Реестр компаний/источников, адаптеры/SQLite, внедряемые провайдеры, закреплённые зависимости | SLA источников, периодические проверки парсеров, стратегия промышленного масштабирования |
| 8. Мониторинг и обратная связь | data-status/ошибки/freshness, trace, docs/quality-monitoring.md, форма экспертной оценки | Пользователь ранее отложил оценку; независимых средних баллов и финансового эффекта нет |
| 9. Вход из Альфа-Бизнеса | Отдельный прототип и сценарий перехода описаны | Настоящая домашняя страница/SSO/банковская интеграция отсутствуют |
| 10. Интерактивность | Диалог, роли, профиль и исходные источники; контрактные/браузерные проверки | Семантическая оценка реальных уточнений на разрешённой модели |
| 11. Агентная логика (PDF, стр. 10) | Источники/банк получены в prepare; заданная оркестрация, вызов source_search через NoExtraTools с пустыми source_ids; trace, checks и stop | **Открыто:** AI не планирует последовательность и не выбирает необходимые инструменты самостоятельно. Правка текста не закрывает продуктовый критерий |
| 12. Объяснимость и связь с контекстом | Ссылки/ID источников, признаки клиента, этапы, даты/неизвестное | Экспертная оценка достаточности оснований и покрытия контекста |

| 11/02 и 14/05: мнение банка влияет на вывод | Частный банковский индекс и отдельная атрибуция; отсутствие позиции видно в публичном режиме | Реальное влияние предоставленной аналитики на новые живые выводы не принято |

| 8: показ изменения ленты под клиента | Выбор компании/роли и повторный анализ в явном FAKE-маршруте | Новый живой показ при stop запрещён |
| 8: дополнительные схема/API/модель данных/тесты | Описания в [архитектуре](../../architecture.md) и [проверках](../../testing.md) | Дополнительные материалы не заменяют работающий прототип |

Локальные измерения относятся к истории: восемь генераций основного пилота и две более ранние пробы (8+2). В stage1 новых локальных inference не было. Независимый review выполнил 23 offline-проверки, подтвердил карантин CFO и отсутствие локальных ID в разрешённом списке кейса (PDF, стр. 12). Это не новая генерация и не приёмка полезности.

Независимая техническая проверка относится к предыдущему архиву. После редактуры автор изменений сам проверил новый комплект: полный прогон кандидата, совпадение исполняемых файлов и проверка финальной распаковки. Независимая приёмка новых изменений остаётся открытой. Инженерные результаты не подтверждают пользу рекомендаций. Публикацию разрешает владелец. Точный SHA256 архива хранится в отдельном `.sha256` рядом с ZIP.
