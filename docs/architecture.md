# Архитектура

Пользователь работает в React-интерфейсе: компания → роль → анализ → лента → карточка → источники и уточнение. Nginx обслуживает сборку и передаёт `/api` в FastAPI. В dev-режиме эту функцию выполняет Vite. Backend хранит запуски, карточки и диалог в SQLite.

## Анализ

В режиме `mvp_offline` приложение использует `ProfileRepository`, `NewsRepository`, `BankRepository`, `AnalysisPipeline` и `DialogueService`. Backend планирует анализ, получает ограниченный контекст компании, до десяти новостей и до трёх банковских фрагментов на событие. Затем он ранжирует события по роли CFO/COO, вызывает модель и проверяет схему, ссылки, экспозицию компании и атрибуцию банка. В offline-режиме цепочка допускает ограниченную коррекцию ошибки валидации; при ошибках бюджета, доступа или неопределённом исходе она останавливается. LIVE не допускает коррекции вторым вызовом.

Fake-модель возвращает детерминированный кандидат. Реальная продуктовая агентная цепочка выполняет планирование, инструменты, проверку и адаптацию даже при fake transport; это не подтверждает качество реальной генерации. `agentic_fixture` демонстрирует ту же основу на отдельном фиксированном корпусе. `deterministic_demo` предоставляет прежний компактный деморежим.

Приложение резервирует run до модели, фиксирует fingerprint входов и кэширует терминальные результаты. Повтор ключа с прежним запросом возвращает сохранённый результат; изменённый запрос с тем же ключом даёт 409. Неопределённый исход не разрешает повтор генерации. Trace содержит этапы, статусы и ID без prompts и скрытых рассуждений.

## Происхождение

Факты, позиция банка и AI-сценарии имеют разные типы. Карточка хранит ссылки на источники, даты и locators. Источник банковской позиции должен иметь дату; исторический документ не представляет текущую позицию. Поиск FTS даёт лексические совпадения и не доказывает смысловую релевантность.

Пользовательский ответ поступает как атрибутированный непроверенный источник. Версия контекста входит в следующий анализ своей company/role. Backend проверяет company, role, insight и snapshot для карточек и диалога. Эти локальные проверки не заменяют банковский IAM.

## Границы

HTTP не выбирает engine, файловые пути или broker transport. API читает локальную новостную БД; отдельный RSS adapter не выполняет fetch внутри API. В Compose входы read-only, runtime volumes раздельные, контейнеры работают без root. SQLite рассчитан на локальный прототип. [Ограничения](limitations.md) определяют границы оценки и эксплуатации.
